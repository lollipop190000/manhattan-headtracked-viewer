# 0002: Name and Spider-Man branding

- Status: Proposed
- Proposed by: @SWTY7
- Affects: design, character, audio, all public text
- Date: 2026-10-13
- Supersedes: none

## Question

The idea is a Spider-Man style game. The repository is public and has a public MIT-licensed release. How closely do we tie the game to the Spider-Man name, suit, logo, music and sounds?

## Options

### A. Original hero inspired by web-swinging

Own name, own suit design, own web effects and sounds. Safe to share publicly, put in a portfolio, show at school events. The fantasy is the same, only the trademark is missing.

### B. Use Spider-Man openly for private demos only

Marvel and Sony own the name, character and logo. A school demo is low risk in practice, but anything on a public repo or release is visible to everyone, and the MIT licence does not cover assets we do not own.

### C. Use Spider-Man openly everywhere

Highest appeal, highest risk of a takedown. Not recommended for a public repo.

## Recommendation

A for everything in the repository and releases (code, file names, art, audio). In a private pitch or conversation the team can still say "Spider-Man style". Working title **Manhattan Swing** until the team picks a real name. Mixed approach B stays possible for a local, not-uploaded demo build, but nothing branded goes into Git.
