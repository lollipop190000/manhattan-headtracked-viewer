# 보조 웹 스윙과 개발 도시

기본 모드는 중력이 적용되는 이동입니다. 화면을 한 번 클릭한 뒤 높은 건물을 조준해 다시 좌클릭하면 자동 도약하고, 줄이 도착한 다음 스윙합니다. 수동 점프는 Space입니다. 마우스와 `HandAimController.Fired(Ray)`는 같은 발사 경로를 사용하며 실제 조준 레이가 250m 이내의 로드된 건물 충돌 프록시에 맞아야 합니다.

| 입력 | 동작 |
|---|---|
| 좌클릭 | 발사 / 기존 줄을 해제하고 재발사 |
| 우클릭 | 추가 도약 없이 줄 해제, 속도 유지 |
| E / Q | 줄 감기 24m/s / 풀기 32m/s |
| R | 자유 비행과 중력 이동 전환 |
| Space | 지상 점프 / 스윙 해제 및 도약 / 벽 점프 |
| W / S | 가속 보조 / 제동 |
| A / D | 완만한 좌우 조향 |
| V | 자동 시점 켜기 / 끄기 |
| [ / ] | 보조 강도 감소 / 증가 (0~1) |
| Esc | 메뉴 및 이동 일시정지 |

중력은 9.81m/s², 최대 속도는 70m/s, 물리 간격은 최대 1/120초입니다. 줄은 팽팽할 때만 장력을 적용하고 해제 시 관성을 유지합니다. 기본 보조에는 높은 곳 명중 시 지상 도약, 느린 스윙의 접선 가속, 최대 10m/s의 줄 정리, 진행 방향을 따라가는 완만한 시점 회전이 포함됩니다. E/Q 입력은 자동 줄 보조보다 우선하며 보조 강도 0으로 비교할 수 있습니다. 머리 움직임 자체는 조향 힘을 만들지 않습니다.

공중에서 W를 누르며 벽에 접근하면 최대 2초 동안 벽 달리기를 합니다. 줄은 벽 달리기 진입 시 해제합니다. 입력 해제, 낮은 속도, 벽 끝에서는 낙하하고 Space로 벽 밖으로 점프합니다.

## 구성

- `SwingPhysics`: 중력, 줄 길이 제약, 접촉, 조향, 벽 달리기 상태.
- `WebSwingMotionInput`: 기존 `IMotionInputSource` 어댑터, 발사 도착, 보조, 도시 좌표 물리.
- `TraversalCollision` / `CitySolidRecovery`: 경로 검사, 미끄러짐, 겹침 복구, 상주 건물 외곽선 충돌. 자유 비행에도 적용합니다.
- `MouseWebShooter`: 입력 연결과 HUD. `WebRopeVisual`: 발사, 느슨함, 장력, 해제 잔상.
- `AfternoonRenderProfile`: 빠른 이동과 벽 근접 시 TAA 잔상 대신 FXAA 사용.

줄 길이 제약과 벽 충돌이 양립하지 않으면 줄을 해제합니다. 다른 건물이 줄 경로를 막아도 해제하며 모서리 감기는 지원하지 않습니다. 건물 충돌은 단순화된 외곽선이므로 세부 장식과 다를 수 있습니다. 지면은 도시 기준 평면과 로드된 충돌 프록시를 사용합니다.

## 작은 개발 도시 / 전체 도시

```powershell
.\tools\build.ps1 -CityProfile Development
.\tools\build.ps1 -CityProfile Full -OutputPath C:\Builds\TraversalFullPlayer\ManhattanViewer.exe
```

미커밋 소스로 개발 빌드할 때만 `-AllowDirty`를 추가합니다. `tools/development-region.json`은 중심 X1225/Z3585, 반경 450m 원과 십자 통로(각 방향 1800m, 반폭 150m)를 선택합니다. 현재 도시 입력에서 10,038개 중 612개 타일입니다. 전체 원본 입력과 기존 전체 플레이어는 별도로 보존합니다.

`CityBuildProfileScope`는 빌드 중 카탈로그와 Addressables를 임시 필터링하고 바이트 백업으로 복원합니다. 중단된 빌드의 `work/city-profile-backup/manifest.json` 복구 기록을 지우지 마세요. 다음 빌드가 먼저 복구합니다.

## 검증 기록 (2026-10-13)

보조 이동 및 충돌 변경에서 DataOnly 164개 중 162개 통과/환경상 2개 건너뜀, PowerShell 검증 8개, EditMode 318개, GPU PlayMode 184개, Windows 플레이어 검증 20개가 통과했습니다. 실제 플레이어에서 높은 건물 조준 후 클릭만으로 자동 도약과 스윙(관측 15.8m/s), 자동 시점과 벽 근처 착지를 확인했습니다. 최종 E/Q/R 복원은 입력 바인딩과 안내 변경입니다.

사용자가 보고한 PowerShell 빨간 오류와 종료는 원인이 아직 확정되지 않았습니다. 확보한 플레이어 로그는 정상 종료 경로를 보였으며 재현 테스트에서 비정상 종료가 관측되지는 않았습니다. `TRAVERSAL_QUIT_REQUEST` 로그를 추가했습니다. 실제 손목 장치 연결 및 펌웨어는 검증 범위 밖입니다.


## 벽 반사와 머리 조향 보조

스윙 중 벽에 충돌하면 줄을 해제하고 벽 바깥으로 반사합니다. 벽에 평행한 속도는 98% 유지하며, 법선 속도는 65%(최대 18m/s)로 반사합니다. 이후 0.4초 동안 벽 쪽 조향 힘을 억제합니다. 스윙 중에는 W를 누르고 있어도 충돌 직전에 벽 달리기로 강제 전환하지 않습니다. 벽 달리기는 줄을 놓은 공중 상태에서 W로 진입합니다.

H는 머리 조향 보조를 켜고 끕니다(기본 켜짐). 플레이를 시작할 때의 머리 좌우 위치를 중심으로 잡고, 2.5cm 이내 움직임은 무시합니다. 한 방향 움직임이 0.18초 지속되면 약한 좌우 조향을 서서히 적용합니다. A/D 입력이 우선하며, 메뉴·자유 비행·트래킹 해제·오래된 관측(200ms 이상)에서는 적용하지 않습니다. 트래킹 재연결 시 중심을 다시 잡습니다. 눈 위치 추정을 이용한 머리 이동 보조이며, 눈동자 시선 자체를 조향하는 기능은 아닙니다.

스윙의 접선 가속 보조는 34m/s 미만에서 12m/s²입니다. S 제동 시 보조를 멈추고, 줄 해제 시 현재 속도를 유지합니다. 보조 강도 0에서는 자동 가속과 머리 조향을 적용하지 않습니다. 실제 사용자 트래킹의 조작감은 추가 플레이 평가가 필요합니다.
