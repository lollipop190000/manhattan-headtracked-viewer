# 웹 스윙: 좌클릭 유지 방식

화면을 한 번 클릭해 마우스를 잡습니다. 높은 건물을 조준하고 **좌클릭을 누르고 있으면** 발사 후 줄이 붙습니다. **버튼을 놓으면 즉시 해제**하며 현재 속도를 유지합니다. 도착 전에 놓으면 발사도 취소합니다. 지상에서 높은 곳을 조준하고 줄이 실제로 도착할 때까지 유지하면 한 번 도약합니다. 도착 전에 놓은 짧은 클릭은 도약하지 않습니다. 길게 유지해도 자동 재발사는 하지 않습니다.

| 입력 | 동작 |
|---|---|
| 좌클릭 유지 | 발사 후 거미줄 유지 |
| 좌클릭 놓기 / 우클릭 | 줄 해제, 추가 추진 없음 |
| E / Q | 줄 감기 24m/s / 풀기 32m/s |
| R | 자유 비행 / 중력 이동 전환 |
| Space | 지상 점프 / 스윙 도약 / 벽 점프 |
| W / S | 전진 가속 / 제동 |
| A / D | 좌우 조향 |
| Esc | 메뉴. 이동 정지 및 줄 해제 |
| [ / ] | 조향 보조 강도 조절 |

기본은 고정된 카메라 방향과 기존 헤드트래킹 투영입니다. 추가했던 머리 조향과 자동 시점은 코드에서 제거했습니다. 스윙이 화면 AA를 덮어쓰지 않고 저장된 TAA 설정을 그대로 사용합니다. 스윙 중에는 접선 방향으로 52m/s까지 가속을 보조합니다. S 제동 또는 보조 강도 0에서는 중단합니다. 해제 후에는 추가 추진 없이 관성을 유지합니다. 자동 길이 회수는 이미 생긴 여유만 제거하며 추가 추진을 주지 않습니다. 개발용 게임 설정은 중력 24m/s², 최대 속도 95m/s, 물리 간격 최대 1/120초입니다. 높은 곳에 발사해 도약한 뒤 필요한 경우 W/E를 사용합니다. 조준은 실제 건물 충돌 프록시에 맞아야 하며 최대 사거리 250m입니다.

스윙 중 벽 충돌은 줄을 해제하고 바깥으로 반사합니다. 접선 속도 98%, 법선 속도 65%(최대 18m/s)를 유지하고 0.4초간 벽 쪽 조향 힘을 억제합니다. 줄을 놓은 공중 상태에서 W로 벽에 접근하면 최대 2초간 벽 달리기, Space로 벽 점프를 합니다. 자유 비행도 충돌을 적용합니다.

거미줄은 기본적으로 곧게 표시합니다. 붙어 있는 동안 앵커 쪽으로 이동하며 생긴 여유 길이를 회수해 팽팽하게 유지합니다. E/Q 입력 중에는 수동 감기·풀기가 우선하며, Q를 놓으면 다시 여유 길이를 회수합니다. 줄과 손은 해당 프레임의 헤드트래킹 갱신 뒤에 업데이트합니다.

기존 트래킹 패키지와 개인 보정 값은 변경하지 않습니다. 머리 조향과 자동 카메라 토글(H/V)은 제거했습니다.

## 개발 도시

`tools/development-region.json`은 중심 X1225/Z3585, 반경 450m 원과 십자 통로(각 방향 1800m, 반폭 150m)를 선택합니다. 현재 10,038개 중 612개 타일입니다.

```powershell
.\tools\build.ps1 -CityProfile Development
.\tools\build.ps1 -CityProfile Full -OutputPath C:\Builds\TraversalFullPlayer\ManhattanViewer.exe
```

미커밋 개발 소스는 `-AllowDirty`를 추가합니다. 원본 전체 도시와 기존 플레이어는 보존합니다. `CityBuildProfileScope`의 임시 필터는 빌드 종료 시 복원됩니다. 중단 복구 기록 `work/city-profile-backup/manifest.json`은 다음 빌드가 복구하므로 삭제하지 마세요.

## 구현과 한계

`SwingPhysics`는 물리, `WebSwingMotionInput`은 이동/줄 상태, `MouseWebShooter`는 입력, `TraversalCollision`/`CitySolidRecovery`는 충돌, `WebRopeVisual`은 표현을 담당합니다. 물리는 도시 좌표로 계산합니다. 벽 탐색은 벽 달리기 입력이 있을 때 수행하고, 이동 하위 단계마다 반복하던 전체 Transform 동기화는 샘플당 한 번으로 줄였습니다. 건물 외곽선 충돌은 경계 상자로 먼저 걸러냅니다.

줄이 건물에 막히면 충돌 프록시 경계 상자의 모서리를 우회하고, 가장 가까운 모서리를 실제 장력 기준점으로 사용합니다. 시야가 열리면 감긴 부분을 풉니다. 최대 12개 경로점으로 제한하며 안전한 경로가 없거나 충돌과 줄 길이가 양립하지 않으면 해제합니다. 단순화된 건물 외곽선은 세부 장식과 다를 수 있습니다. 실제 손목 하드웨어와 사용자 머리 움직임의 편안함은 별도 평가가 필요합니다. 이전 PowerShell 오류 종료의 원인은 확정되지 않았습니다.

`--traversal-diagnostics`를 플레이어에 전달하면 입력·줄 상태, 프레임 시간, 이동 계산 시간, 트래킹 관측 지연을 로그에 남깁니다. 일반 실행에는 이 기록을 켜지 않습니다.


## 1인칭 장갑 손

좌우 각각 관절이 있는 스킨 메시를 사용합니다. 클릭 유지 시 0.12초간 손목 발사 자세를 취하고 거미줄이 나가며, 도착하면 손가락을 굽혀 붙잡는 자세로 전환합니다. 발사·유지 중인 한 손만 보이며 버튼을 놓으면 짧게 팔을 내린 뒤 숨깁니다. 평소와 메뉴에서는 손을 숨깁니다. 마우스 잠금 상태에서는 마지막 좌우 조준 이동으로 손을 선택합니다. 잠금이 없는 입력 및 손목 레이는 화면 좌우 위치를 사용합니다.

팔은 카메라에 붙인 HUD가 아니라 물리 화면 평면에 배치하고 기존 창틀과 같은 깊이 검사를 사용합니다. 아래·옆 프레임 뒤에서 팔이 올라오고 손목이 화면 평면 앞쪽으로 나옵니다. 창틀 표시 설정은 유지합니다. 장갑은 자체 생성한 관절 모델이며 영화/게임 원본 캐릭터 자산은 아닙니다. 복잡한 거미줄 다발 발사 효과는 후속 범위입니다.


손목은 보통 화면 평면 앞 약 16cm에 배치하고, 팔꿈치도 앞으로 당겨 창틀 위를 가로지르게 합니다. 관측자와 너무 가까워지지 않도록 눈 위치 기준으로 깊이를 제한합니다. 공기 저항은 0.01/s, 지상 도약은 위로 20m/s 및 조준 수평 방향으로 24m/s입니다. 머리 추적 투영이나 카메라 FOV는 속도 효과를 위해 변경하지 않습니다.
